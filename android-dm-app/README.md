# The Case DM Queue — Android

Отдельное Android-приложение для работы с очередью Instagram-контактов и уже подготовленных писем.

## Что делает
- импортирует CSV со связкой `instagram -> message`;
- хранит очередь и статусы локально на телефоне;
- копирует конкретное письмо;
- открывает Direct нужного аккаунта через `ig.me/m/<handle>`, а если это не сработало — профиль;
- при включенном Accessibility-помощнике пытается вставить письмо в поле Direct;
- **никогда не нажимает Send автоматически**;
- не хранит логин/пароль Instagram и использует уже авторизованную официальную Instagram-сессию.

## CSV
Минимум:
```
instagram,message
brand_one,"Готовый текст письма"
```

Расширенный формат:
```
instagram,brand,message,language,note
brand_one,Brand One,"Готовый текст",ru,"почему выбран аккаунт"
```

В CSV поддерживаются кавычки и многострочные письма.

## Тестирование
1. Установить debug APK.
2. Открыть «Настройки» → «Открыть Instagram и проверить вход».
3. При необходимости войти в Instagram **в самом Instagram**.
4. В Android Accessibility включить сервис The Case DM Queue, если нужна автovставка.
5. Импортировать CSV.
6. Открыть запись.
7. Нажать «Скопировать + открыть Instagram + вставить».
8. Проверить правильность аккаунта и текста.
9. Нажать «Отправить» вручную.
10. Вернуться в приложение и отметить запись отправленной.

## Ограничение
Instagram меняет интерфейс и deep links. Поэтому базовый устойчивый сценарий всегда остается: скопировать сообщение + открыть профиль/Direct. Accessibility-вставка — вспомогательный слой, а не гарантированный API Instagram.
