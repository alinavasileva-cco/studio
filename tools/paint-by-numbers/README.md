# Paint-by-Numbers — авторская версия V7 (19 цветов)

Кодовый генератор картины с плавными границами и художественными дополнениями к **лицу девушки, кимоно и цветам фонариков**. Проект развивается в ветке `feature/paint-by-numbers-19`; не является форком, сборкой или копией C++/Qt-исходников [ColoringByNumberCreator](https://github.com/victor-prog-1998/ColoringByNumberCreator), но использует сходную концепцию ручной коррекции палитры.

## Изменения V7

- `art_direction.py` — редактируемые **замкнутые кривые Безье** для формы лица, бровей, двух глаз, радужек, бликов, губ, уха, складок кимоно, лепестков и веточек на фонариках. Сначала восстанавливается овал лица, затем на него накладываются отдельные цветовые поля глаз и губ. Это не рисунок линиями поверх схемы: все авторские элементы включены в индексированную карту и получают номера.
- `refine_geometry.py` — векторная разбивка строится из карты с 2–3-кратной плотностью, чтобы устранить крупные пиксельные ступени. Интерполяция работает по маскам 19 классов, а не RGB: **каждый полученный пиксель имеет ровно один ID цвета**.
- `smooth_geometry.py` — контуры по общей сети границ: узлы пересечений сохраняются, длинные цепочки переводятся в плавные кубические кривые. Соседние зоны не обводятся двумя разными путями.
- `pbn_creator.py` — финальная уборка микроостровков после сглаживания и обновлённые CLI-параметры `--vector-scale 1|2|3`, `--partition-blur`, адаптация размера номера к масштабу; матрица `segment_id` создаётся заново после последнего художественного прохода.

## Воспроизвести

```bash
python -m pip install -r requirements.txt
python pbn_creator.py \
  --input examples/lanterns_indexed_19.png \
  --palette examples/palette_19.csv \
  --out results_v7 \
  --artistic-retouch --vector-scale 3 --partition-blur 1.7 \
  --outline-mode smooth --curve-sigma 3.5 --curve-epsilon 2.5 \
  --min-area 35 --min-radius 3.3 --passes 4 \
  --canvas-width 40 --canvas-height 60
python -m unittest discover -s tests -v
```

Пример `examples/lanterns_indexed_19.png` не опубликован в общедоступном репозитории: он выдаётся отдельно в комплекте ZIP. Режим `--artistic-retouch` привязан к конкретной композиции 639 × 958 пикселей. Для других иллюстраций отключи его либо измени координаты художественных фигур.

**Результат локального запуска V7:** 19 цветов, 601 связная цветовая область, 601 цифровой номер, ноль неприсвоенных пикселей, ноль областей с двумя номерами; 152 области с радиусом меньше 5 исходных пикселей. Многие цифры в них слишком мелкие для чтения на основном листе: полный PDF содержит увеличения; промышленная пригодность **не подтверждена без пробной печати**.

Экспорт: `numbered_19.svg`, `numbered_19_40x60.pdf`, `paint_by_numbers_19_full.pdf` (17 страниц), `color_19.png` (строгая палитра), `color_preview_antialiased.png` (экранная визуализация), `palette_19.csv`, `regions.csv`, `palette_indices.png`, `region_ids.npz` и `qa_report.json`.

**Техническое ограничение:** 100%-ное неперекрывающееся покрытие строго доказано для индексированной матрицы пикселей. Векторные кривые являются сглаженным представлением общей растровой границы: формальная топология непрерывных кривых пока не доказана математически; требуется визуальный препресс-контроль.
