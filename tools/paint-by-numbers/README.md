# Paint-by-Numbers 19 — генератор с плавными общими границами

Независимая реализация на Python. Использует идеи рабочего процесса из [ColoringByNumberCreator](https://github.com/victor-prog-1998/ColoringByNumberCreator), но **не содержит и не изменяет C++/Qt-код этого проекта**.

## Что изменено в версии со сглаживанием

1. Все пиксели принадлежат единственному `segment_id` и `paint_id` (1–19); каждый компонент связен по 4 соседям.
2. Вместо обводки по пиксельной сетке строится **единственный граф общих границ** между соседними областями. Граф разбивается на неповторяющиеся цепочки; длинные цепочки сглаживаются, узловые точки сохраняются, обводки соседних полей не дублируются.
3. Для исключения мелких «крошек» и очень тонких цветовых полос применяется последовательное слияние областей с близкими соседними цветами. Узкие детали лица сохраняются с меньшим порогом.
4. Все 19 цветов и номера пересчитываются из одной индексированной карты. SVG содержит самостоятельные `<path id="segment-N">` и `<text id="number-N">` для **каждой** области.
5. Цифры используют один шрифт DejaVu Sans. Если 7,8 пикселя не помещаются внутри участка, размер конкретного номера автоматически уменьшается. Это **не гарантирует комфортную читаемость** микросегментов на физическом листе; для них включены дополнительные крупные страницы PDF.
6. Для конкретной иллюстрации с девушкой и фонариками доступна **опциональная художественная правка глаз, радужек и губ** (`retouch_lanterns.py`) с сохранением сегментации. Коррекция написана для входного изображения **639 × 958 пикселей** и не применяется к другим сюжетам.
7. Цветное изображение `color_19.png` содержит строго 19 исходных цветов. Дополнительный `color_preview_antialiased.png` — только экранный образец со сглаживанием, а не матрица красок.

## Быстрый запуск

```bash
python -m pip install -r requirements.txt
python pbn_creator.py \
  --input examples/lanterns_indexed_19.png \
  --palette examples/palette_19.csv \
  --out output \
  --face-retouch \
  --outline-mode smooth \
  --curve-sigma 1.6 \
  --curve-epsilon 0.88 \
  --canvas-width 40 --canvas-height 60
```

При самостоятельной фотографии: `python pbn_creator.py --input photo.jpg --out output --width 800 --protected ""`.

Пример изображения находится **только в скачиваемом комплекте**, но не в публичной ветке GitHub. Укажи путь к своему изображению, если запускаешь код из GitHub.

## Выходные файлы

- `numbered_19_40x60.pdf` — самостоятельная схема для печати, масштаб 40 × 60 см.
- `paint_by_numbers_19_full.pdf` — схема, цветной образец, палитра, шесть листов A4, увеличения лица, глаз, губ, одежды, фонариков и воды, технический отчёт.
- `numbered_19.svg` — индивидуальные редактируемые объекты областей и номеров, плюс общие сглаженные контуры.
- `numbered_19.png` — превью, отрисованное **из того же SVG**, а не по отдельной растровой сетке.
- `color_19.png` — точная палитра, `color_preview_antialiased.png` — экранное сглаживание.
- `palette_indices.png`, `region_ids.npz`, `regions.csv`, `palette_19.csv`, `qa_report.json` — данные для контроля.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Проверяются связность, уникальность ID, принадлежность каждой точки одному цвету, обход границ без дублирования и сохранение оригинальных узлов топологии при сглаживании. После построения SVG количество реальных `<path id="segment-*">` и `<text id="number-*">` проверяется повторно.

**Ограничения:** геометрия SVG — плавная графическая аппроксимация дискретной карты. Из-за очень узких фрагментов некоторые номера требуют просмотра на увеличенной странице. Авторская правка лица — художественная адаптация, не точная попиксельная копия. Промышленная пригодность не подтверждается без пробной печати и ручной художественной проверки.
