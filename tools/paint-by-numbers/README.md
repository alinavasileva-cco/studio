# Paint-by-Numbers — авторская версия V6 (19 цветов)

**Python-проект с воспроизводимой сегментацией и ручной художественной геометрией.** Реализован независимо от [ColoringByNumberCreator](https://github.com/victor-prog-1998/ColoringByNumberCreator) (C++/Qt), без изменения чужих исходников.

## Новое в V6

- `art_direction.py`: **134 редактируемые замкнутые векторные фигуры**, выполненные кодом с помощью кривых Безье. Улучшены веки, глаза и губы девушки, пряди, складки ткани и отдельные лепестки сакуры. На трёх крупных фонариках прорисованы самостоятельные цветочные ветви, листочки и соцветия.
- Каждая фигура **вносится в 19-цветную индексированную карту *до* сегментации**, а не поверх пронумерованной схемы. Поэтому ей назначается цвет; окончательные области пересчитываются, а потом подписываются.
- `smooth_geometry.py`: сохраняет точные узловые точки общей сетки границ, но прорисовывает линии с плавными кривыми, без квадратиков пикселей и двойной обводки соседних зон.
- Программа контролирует связность регионов, полное покрытие каждого пикселя, ровно одно числовое поле на регион и использование только действительных ID красок. Для узких зон номера уменьшаются, в полном PDF есть увеличенные фрагменты.

> Важно: сглаженные контуры — визуальная векторная аппроксимация растровой карты. 100%-ное покрытие проверяется **на карте сегментов**, а не как строгая математическая топология всех кривых PDF. Для коммерческой печати необходимы художественная приёмка и пробный отпечаток.

## Воспроизвести результат

```bash
python -m pip install -r requirements.txt
python pbn_creator.py \
  --input examples/lanterns_indexed_19.png \
  --palette examples/palette_19.csv \
  --out result_v6 \
  --artistic-retouch \
  --outline-mode smooth \
  --curve-sigma 2.0 \
  --curve-epsilon 1.3 \
  --canvas-width 40 --canvas-height 60
```

Чтобы выполнить это с копией из GitHub, положи свой исходный PNG на место `examples/lanterns_indexed_19.png`. **Иллюстрация не опубликована на GitHub**: пример входного файла включён в отдельный скачиваемый ZIP результата. По просьбе пользователя не публикуем её в открытом репозитории.

Режим `--artistic-retouch` предназначен **только для данной иллюстрации 639×958**, с её фиксированными координатами. Для другого сюжета запусти без режима или адаптируй векторы `art_direction.py`. Прежний `--face-retouch` сохранён для сравнения V5 и новой версии. Если оба аргумента включены, приоритет у `--artistic-retouch`.

## Экспорт

- `numbered_19.svg` — редактируемая схема с `segment-ID`, `number-ID` и единой сетью плавных контуров.
- `numbered_19_40x60.pdf` — один печатный лист 40×60 см.
- `paint_by_numbers_19_full.pdf` — 17 страниц: схема, цветовой эталон, палитра, 6 листов A4, увеличенные фрагменты и QA.
- `color_19.png` — точная постеризация из **ровно 19 цветов**.
- `color_preview_antialiased.png` — только экранная сглаженная версия, не эталон палитры.
- `region_ids.npz`, `palette_indices.png`, `regions.csv`, `palette_19.csv`, `qa_report.json` — цифровая карта областей, состав и результаты проверок.

## Тесты

```bash
python -m unittest discover -s tests -v
```

В проверенном локальном прогоне V6: 11 тестов прошли, 600 связных регионов и 600 чисел; 19 цветов, 0 неприсвоенных пикселей, 0 регионов с несколькими номерами. **88 регионов имеют радиус вписанного круга менее 5 пикселей** — это не ошибка нумерации, а реальное ограничение читаемости; они представлены в увеличенных фрагментах. Эти числа относятся к текущему входному изображению, а не ко всем будущим.
