# Paint-by-Numbers 19 — воспроизводимый генератор на Python

Независимый кодовый проект. Вдохновлён процессом из [ColoringByNumberCreator](https://github.com/victor-prog-1998/ColoringByNumberCreator), **не является копией его C++/Qt исходников**.

## Что делает

- Преобразует изображение в фиксированную палитру **19 цветов** (либо принимает уже проиндексированную карту с индексами `0..18`).
- Исправляет мелкие и узкие сегменты, сохраняя зону лица с пониженным порогом слияния.
- Вычисляет **4-связные компоненты**: каждый пиксель принадлежит ровно одному `segment_id` и `paint_id`.
- Рисует **общие границы** соседних сегментов без пары разъезжающихся обводок.
- Для **каждого сегмента** вычисляет максимум расстояния до границы и ставит там **ровно одну цифру** из 1–19 одним шрифтом.
- Экспортирует `numbered_19.svg`, PNG, PDF 40×60 см, увеличенные листы, палитру, `region_ids.npz` и отчет.
- Не выдаёт результат за промышленно готовый без проверки удобства закрашивания и пробной печати.

## Запуск

Python 3.11+:

```bash
python -m pip install -r requirements.txt
python pbn_creator.py --input my-image.png --out result \
  --canvas-width 40 --canvas-height 60
```

При исходном RGB-фото:

```bash
python pbn_creator.py --input own-photo.jpg --out result --width 800 \
  --min-area 40 --min-radius 3 --passes 5
```

`--protected x,y,w,h` принимает доли изображения в диапазоне 0–1, по умолчанию вокруг лица женщины в примере. Для иного сюжета задайте вручную область лица или `--protected ""`.

## Результаты

| Имя | Содержание |
| --- | --- |
| `paint_by_numbers_19_full.pdf` | Схема 40×60 см, образец, палитра, листы A4, увеличения и QA |
| `numbered_19.svg` | SVG с ID каждой области и нумерацией |
| `color_19.png` | Постеризация в 19 цветов |
| `numbered_19.png` | Номера и границы для просмотра |
| `region_ids.npz` | Две полные матрицы сегментов и красок |
| `regions.csv` | ID, площадь, номер краски и координаты метки |
| `qa_report.json` | Количество областей, пропусков, число узких регионов |

**Ограничение:** маленькие объекты (включая зрачки) могут быть слишком узкими, чтобы размер номера был комфортен на основном листе. Код ставит номер в каждый регион, а узкие регионы дополнительно увеличивает на отдельных листах; это не гарантирует абсолютную удобочитаемость без художественной ручной корректировки. SVG для корректировок есть, но интерактивный настольный редактор не включён.

## Контрольные инварианты

1. `np.count_nonzero(segment_id==0) == 0`.
2. Один сегмент относится к одному цвету `paint_id`.
3. Число label-тегов = числу сегментов.
4. Индексы палитры лежат в `1..19`.
5. Полная карта цветов и контурная схема происходят из **одной** индексированной матрицы.
